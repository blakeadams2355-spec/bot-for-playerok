# CRM-бот для товарного бизнеса

Продвинутый Telegram-бот для управления продажами и расходами товарного бизнеса.

## Возможности

- ✅ Управление товарами (добавление, редактирование, удаление)
- ✅ Моментальные продажи в один клик
- ✅ Учет расходов
- ✅ Детальная статистика (день/месяц/все время)
- ✅ Экспорт отчетов в PDF
- ✅ Настройка комиссии площадки
- ✅ Категории товаров
- ✅ Расчет прибыли с учетом комиссии
